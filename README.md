Helion Intelligent Workforce Planning System

• Team members: Alya Alremeithi and Mariam Tariq 

• Problem: Outdoor construction workers in the UAE and GCC may face risks caused by extreme heat, humidity, dust, and changing weather conditions. Traditional scheduling methods may not adequately account for these risks.

• Key features: 
Comparison of safety-focused, balanced, and productivity-focused schedules
Interactive schedule selection and approval

• Technologies: HTML, CSS, Javascript, MySQL

• Prerequisites: A modern web browser such as Chrome or Safari

• Installation:
Download the Helion project files from the GitHub repository by clicking Code - Download ZIP.
Extract the ZIP file to a folder on your computer.
Open the extracted Helion project folder.

• Configuration: No configuration is required

• How to run:
Open the Helion project folder.
Double-click the index.html file to open it in a web browser.
Navigate to the Schedule Alternatives page to explore the available scheduling options.

• How to test:
Open the Schedule Alternatives page and verify that the Safest, Balanced, and Fastest schedules are displayed.
Select the Balanced schedule and verify that it is highlighted.
Open the Schedule Review & Approval page and verify that the selected schedule is displayed correctly.
Click Approve Schedule and verify that the status changes from "Awaiting Approval" to "Approved".
Repeat the process with another schedule to verify that schedule selection and approval work correctly.
